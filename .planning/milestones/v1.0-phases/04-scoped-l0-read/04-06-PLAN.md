## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| trusted connector capability → aggregate planner | 能力表决定允许的pushdown形态，不能由wire伪造 |
| source partial/TopN + edited rows → correction engine | old/new contribution、membership与group移动必须完整且只计一次 |
| merged visible values → group/measure builder | row-specific column grants决定可参与排序、group与measure的值 |
| bounded builder → aggregate response | 只有exact完成可返回data，预算/截断/capability失败必须丢弃partial state |
