## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| logical query request → storage read API | type/link/pk/limit来自query compiler，不可信数量仍需storage二次限界 |
| storage mapping → SQLite/PostgreSQL | physical identifiers来自validated ActiveDefinition，不来自wire |
| database cells → typed edit state | 不可信/损坏cells必须fail closed，不能产生错误授权state |
