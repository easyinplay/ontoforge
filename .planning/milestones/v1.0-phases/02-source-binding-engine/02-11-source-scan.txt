==== PROVENANCE BOUNDARY ====
本扫描证明的是：
- 公开面（`examples/`、`ci/`、`crates/**/tests/`、`.github/workflows/`、`CONTRIBUTING.md`）中出现在 catalog / schema / table 位置的物理标识符**全部为中性词**（航空、通用记录、TPC-H / L2 规则的公开通用名、以及 `a`/`c`/`s`/`t`/`other` 之类哑元），不含任何公司专有的集群名、内部库名或业务表名；
- 公开工作流不引用私有测试目标或私有环境变量（门控 C-1），私有入口同时具备环境变量门控与 `#[ignore]` 门控（门控 D-1），贡献文档写明了私有入口的位置约定与禁止提交规则（门控 D-2）；
- 公开面出现的端点串全部是回环地址、容器网络内的服务名（`minio`）、Docker 标准宿主机名（`host.docker.internal`）或仓库内的 S3 桶前缀（`s3://warehouse/`）。

本扫描**不能**证明：
- **数据来源原创性**。机器无法区分「虚构但看起来真实」与「真实但已脱敏」；标识符中性不等于数据原创，也无法证明种子数据、CSV 夹具、示例绑定的每一行取值都来自虚构来源。
- **部署隔离**。仓库内的端点字面量检查不能证明 runner 在实际运行时的网络出口、凭据环境与 secret 注入情况；仓库未声明的 secret、org 级变量、runner 级环境变量在本扫描中不可见。
- 仓库外私有目录（`ONTOFORGE_PRIVATE_FIXTURES` 指向处）的任何内容。

因此本扫描的结果**只**构成 G-02-B / G-02-C / G-02-D 三个 judgment 项的机器可判定部分，其**结论**仍为 `VERDICT: PENDING`，见 `.planning/phases/02-source-binding-engine/02-11-HUMAN-ACCEPTANCE.md`。
