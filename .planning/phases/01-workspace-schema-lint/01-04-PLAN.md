## Phase Goal

**As a** 编写 ontology 的开发者, **I want to** 用 YAML/JSON 编写 ontology 并通过 `ontoforge validate` / `ontoforge lint` 得到带源码定位的诊断, **so that** 定义错误在被存储、action、API 使用之前就被定位修正，且仓库在 Windows 本机 `cargo test` 全绿。

> 来源说明见 01-01-PLAN.md 的 Phase Goal 节。

<objective>
让开发者可以完整定义 object type 与属性：补齐 SCHEMA-02 的全部字段与 SCHEMA-03 的 13 个 base type，实现主键 / title key / items 的结构性校验（ONT-V10、V06，per D-06），并把 aviation 示例扩展为 5 个 object type 的 YAML 版与等价 JSON 版（per D-16），用测试证明两者得到同一 IR。
