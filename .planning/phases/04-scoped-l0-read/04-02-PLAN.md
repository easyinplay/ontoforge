## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ObjectSet wire AST → validator | 客户端可控制递归深度、operator、logical property与literal |
| validated logical query → physical Select | compiler持有ontology binding与scope，唯一知道physical mapping |
