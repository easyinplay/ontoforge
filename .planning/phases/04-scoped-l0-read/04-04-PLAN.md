<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source/edit candidate lanes → Rust overlay | 两个backend返回的候选可能重复、过宽、过期或损坏，不能直接成为结果 |
| merged row → scope/filter/order/projection | 所有可观察membership、order与列都必须使用同一merged-row授权语义 |
| cursor wire payload → executor state | 客户端可篡改或在其他principal/scope/definition/order上下文重放cursor |
| executor work → response page | backend work budget与final output caps必须fail closed且语义独立 |
