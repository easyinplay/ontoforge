## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| logical link metadata → source/edit edge reads | cardinality、endpoints与physical binding必须来自ActiveDefinition |
| edge/FK candidates → target object executor | relation membership不能替代target row/column授权或tombstone处理 |
| nested ObjectSet operands → set algebra | raw/hidden candidate membership不能进入可观察集合代数 |
| composed result → pagination/output | traversal/set必须复用统一order/cursor/version/caps而非自建旁路 |
