<interfaces>
command row 的唯一键严格为 `(principal_id, command_id)`；字段含 action identity、canonical client `params_hash`、状态、最小 receipt、winner chosen time、created/expires timestamps。`CommandClaimOutcome` 至少区分 `Winner`、`Replay(receipt)`、`Reused`；in-flight conflict 不向 caller 暴露内部状态，而是在 bounded wait/cancel policy 内等待 winner 后重新判断。

| Boundary | Description |
|----------|-------------|
| concurrent clients -> command claim | 同主体同键请求可能同参、异参、取消或丢失 response |
| stored receipt -> current caller | durable success 不能绕过当前 action grant，也不能跨主体披露 |
| client JSON -> fingerprint | key order、presence、defaults 与 server values 必须按合同区分，避免 hash confusion |
