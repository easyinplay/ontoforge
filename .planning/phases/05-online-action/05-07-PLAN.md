<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| durable outbox -> external webhook | receiver 不在数据库事务内，可能超时、失败或在响应后发生进程 crash |
| trusted server config -> HTTP client | target URL 和 delivery policy 是运维配置，不能由 untrusted Action request 控制 |
| public host/API -> storage mutation | user-visible mutation 必须经过 Action authorization/idempotency 或 audited import |
| ignored tests -> CI verdict | filter/config 错误可能让零个高风险 tests 被执行却返回成功 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-21 | Repudiation | webhook duplicate/retry | medium | mitigate | durable attempts/lease/delivered timestamps与稳定 event_id；receiver去重合同 |
| T-05-22 | Spoofing | webhook target | high | mitigate | target只来自 trusted WebhookConfig，request serde无 URL/header override |
| T-05-23 | Elevation of Privilege | raw storage mutation route | critical | mitigate | production source caller allowlist、Action-specific transaction和reserved audited import provenance |
| T-05-24 | Tampering | CI false green from ignored/filter mismatch | high | mitigate | 每个 PG/Trino target非零 discovery assertion后真实 `--ignored` execution，记录 executed count |
| T-05-SC | Tampering | Cargo dependency resolution | high | mitigate | 不安装 package，只复用 workspace reqwest/wiremock/tokio；所有 cargo commands带 `--locked` |
</threat_model>
