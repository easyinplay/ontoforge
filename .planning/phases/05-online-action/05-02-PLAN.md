<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client JSON -> Action runtime | 参数、expected tokens 与 batch 大小均不可信；principal/scope/limits 不来自 wire |
| merged row -> criteria/rule engine | 只有逐行可见列可进入 criteria，完整状态只在可信编排内部用于授权 |
| planned edits -> storage transaction | 每个 property、target 与 post-state 必须在提交前授权 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Spoofing | ActionRequest principal/scope | high | mitigate | request serde 不含主体或 scope；仅接受 host 注入的 verified Principal/PrincipalScope |
| T-05-05 | Information Disclosure | masked submission criteria | high | mitigate | runtime RowVisibility 列覆盖先于 expression 求值，hidden/missing outward shape corpus |
| T-05-06 | Elevation of Privilege | write/post-state/link/release | high | mitigate | ADR-0018 ⑤与⑧逐状态检查，失败统一 ScopeDenied |
| T-05-07 | Denial of Service | batch/rule/source expansion | medium | mitigate | trusted ActionLimits + checked counters，在任何 external I/O 前拒绝超限 |
| T-05-SC | Tampering | Cargo dependency resolution | high | mitigate | 不安装 package，只使用锁定 workspace dependencies；cargo 全带 `--locked` |
</threat_model>
