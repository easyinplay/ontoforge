<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test harness -> transaction internals | fault selector 只能在 test-support build 使用，不能来自 client request |
| concurrent Action services -> PostgreSQL | 两个不可信请求跨独立连接竞争同一逻辑 rows/commands |
| SQL success -> transaction commit | 任一后续 stage 或 commit 前错误必须撤销之前所有可见写入 |
