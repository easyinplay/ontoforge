## Architecture Conditions

- Keep the Trino/source sampling phase outside the write transaction as ADR-0018 specifies. Inside the transaction, lock the full edit read set in stable `(kind, type, pk)` order and compare each locked edit version with the pre-read version; source drift remains the documented non-detection boundary.
- `validate-only` must run the same parameter, source, criteria, write-field and post-state checks, while creating no persisted version-0 lock rows, command record, log or outbox. The plan needs a read-only equivalent of the lock-dependent checks or a transaction that always rolls back.
- Preserve the one-log invariant already implemented by `Commit`: one batch's flattened edits become one `Commit`, with one `event_id`. The outbox stores that same stable event ID and a durable payload; a worker claims pending rows, retries failures with bounded backoff, and marks delivery only after confirmed success. Recipients deduplicate by `event_id` because delivery is at least once.
- Give the Action host a scoped auth/query integration path rather than expanding a raw SQL or public `WriteTx` escape hatch. Audit all other mutation callers against ACTION-07.

## Test And Performance Gate

| Area | Required evidence |
|---|---|
| Atomicity | SQLite and real PostgreSQL: inject failure after edit row, log, command, and outbox stages; all four counts/state unchanged after each rollback. |
| Concurrency | Real PostgreSQL two-connection race for same pk with and without `_version`; exactly one success, other `VersionConflict`. Concurrent same `command_id` returns one cached result and one log/outbox event. |
| Scope | Criteria on masked column, hidden target vs nonexistent target, post-write invisible row, link endpoint and release visibility, validate-only probes, replay after grant removal and delete. |
| Source | Trino available duplicate pk, unavailable source-required path, unavailable all-patched path; verify no Trino call on offline path. |
| Delivery | Crash after DB commit before send; failed webhook retry; crash after successful send before marking delivered; same `event_id` on every attempt. |
| Cost | Record batch size, lock hold time, source calls and outbox backlog. Cap batch size and source calls; avoid network access while holding the write transaction. |
