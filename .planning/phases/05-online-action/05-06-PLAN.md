<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Action planner -> external Engine | source I/O 跨外部服务边界，可能失败、返回重复或泄露物理信息 |
| source rows -> logical overlay | 不可信 source 数据必须 canonicalize、限制行数并按同一 query 语义合并 |
| source sampling -> write transaction | source 是事务前样本；失败必须发生在任何 durable claim/write 之前 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-18 | Denial of Service | source-required Engine outage | medium | mitigate | demand planner、bounded source calls、稳定 EngineUnavailable 和 pre-transaction failure |
| T-05-19 | Tampering | duplicate logical source pk | high | mitigate | 每次实际 pk source read 固定 LIMIT 2，观测两行即 AmbiguousObject 且拒写 |
| T-05-20 | Information Disclosure | Engine/SQL error propagation | high | mitigate | typed error mapping，不返回 URL、SQL 或 physical catalog/schema/table；fake/real corpus |
| T-05-SC | Tampering | Cargo dependency resolution | high | mitigate | 不安装 package，只复用已有 Engine/Trino/query dependencies；cargo 全带 `--locked` |
</threat_model>
