## Phase Goal

**As a** 部署 ontoforge 的开发者, **I want to** 把 object type 与 M:N link 绑定到已有 Trino 的物理表，并用 `ontoforge validate --online` 校验绑定, **so that** 应用与 agent 读到的是企业已有的数据，而 Windows 本机无需 Trino 即可用 SQLite 替身跑通全部测试。

> 来源说明见 02-01-PLAN.md 的 Phase Goal 节。

Purpose: ENGINE-01（自写 client、trace token、两个服务身份）、ENGINE-02（`status()` 探测；`Unavailable` 的完整分类在 02-06）。
Output: `trino` 模块、`config` 模块、`clippy.toml`、两组 wiremock / 配置测试。
</objective>
