## Phase Goal

**As a** 部署 ontoforge 的开发者, **I want to** 把 object type 与 M:N link 绑定到已有 Trino 的物理表，并用 `ontoforge validate --online` 校验绑定, **so that** 应用与 agent 读到的是企业已有的数据，而 Windows 本机无需 Trino 即可用 SQLite 替身跑通全部测试。

> 来源说明：ROADMAP Phase 2 的 `**Goal:**` 行不是 user story 格式。按 Phase 1 先例（`01-01-PLAN.md` Phase Goal 节）由 Goal 原文组成：actor 与 capability 取自 Goal 前半句，outcome 取自 Goal 后半句与 PROJECT Core Value。ROADMAP 原文未改写。
