## Phase Goal

**As a** 部署 ontoforge 的开发者, **I want to** 把 object type 与 M:N link 绑定到已有 Trino 的物理表，并用 `ontoforge validate --online` 校验绑定, **so that** 应用与 agent 读到的是企业已有的数据，而 Windows 本机无需 Trino 即可用 SQLite 替身跑通全部测试。

> 来源说明见 02-01-PLAN.md 的 Phase Goal 节。

<objective>
补齐绑定比对的语义并交付 drift 状态模型：先用 tracer 打通「fixture 缺列 → SQLite 替身 → `check_drift` → Flight 降级、其余健康」，再把 02-05 的跨族判定扩展为 D-13 的完整无损映射表（含 decimal 整数位规则与 timezone 复核），最后写绑定规范文档并用测试把文档中的类型表与代码锁在一起。

Purpose: BIND-03（drift 不匹配时该 object type 降级，其余照常；本 phase 交付库函数与状态模型，D-15）、BIND-02 / D-13（映射表写入绑定规范文档）。
Output: `bind_check.rs` 的完整比对与 drift、`docs/source-binding.md`、两个测试文件。
</objective>
