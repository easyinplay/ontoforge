# ADR-0008 认证与授权

- status: accepted
- date: 2026-10-15

## Decision
- AuthZ：`Authorizer` trait + 自研 RBAC（ontology / object type / action type 级角色），dev 模式也走真实检查，fail-closed；列表先过滤后分页。v2 评估 `cedar-policy` 做行/列级策略。
- AuthN：OIDC JWT（`jsonwebtoken` + 自写 JWKS 缓存）；dev 模式提供本地签发 token。
- action 执行前先授权、再校验 submission criteria，避免错误信息泄露对象状态。

## Rejected
OpenFGA（需额外服务，违背单二进制）、`oso`（开源库停更）、`casbin-rs`（模型表达与 ontology 关系不贴合）。
